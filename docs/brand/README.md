# ArtCraft brand marks

The ArtCraft name, wordmark and logos that upstream EffectCraft keeps in this directory have been
removed from this fork, as [`LICENSE-brand.txt`](LICENSE-brand.txt) requires of a published
modified version: EffectCraft for air/OS ships in air/OS images, so it must not carry the ArtCraft
Marks or present itself as an ArtCraft product. The app shows EffectCraft's own icon where upstream
shows the ArtCraft mark, and this repository credits upstream in plain text only: EffectCraft for
air/OS is based on [EffectCraft](https://github.com/storytold/effectcraft) by the ArtCraft team.
`LICENSE-brand.txt` is kept unchanged as the record of those terms.
